# Spine v02：頭頸連續表面修正，待玩家評閱

日期：2026-11-03。玩家否決v01「個頭都係甩咗」。舊資料及影像留在`../spine-character/`，不能再當作合格版本。母版已接受，修正版動作仍未接受。

## 根因與改法

v01的頭連頸與胸口為兩個獨立attachment，靠衣領重疊；即使父子骨節及骨長正常，材質表面仍會斷開。v02用一張從頭至腰的連續RGBA，整體等比對位，頸部加密同一加權網格，由頭骨經頸骨過渡至胸骨。保留臉部相對胸口轉動，沒有鎖死頭、加圓筒頸件或增加衣領掩蓋。18骨節、六網格，三段原有動作關鍵幀不變。

## 可以看的證據

- `neck-closeup.gif`：實際App近鏡錄影轉出，10fps、320px寬的分享版本，色彩及更新頻率經壓縮。不能用GIF判定原始幀率。
- `neck-closeup.mp4`：同一錄影的H.264版本，正常速度的待機／出拳／受擊，之後0.25倍受擊。
- `neck-closeup.webm`：Playwright原始即時錄影，保留載入起點；GIF／MP4只裁去頭1.7秒載入。
- `right-*.png`／`left-*.png`：390×844、DPR2的實際App，待機0.8秒、出拳0.35秒、受擊0.19秒。左右各三張。
- `before-after.png`：v01與v02受擊相同0.19秒、同尺寸鏡頭截圖。只裁同一區域及相同倍率，紅框標頭頸；沒有逐頭調整大小。
- `browser-report.json`：Chromium、Linux WebKit實播、左右、存檔及錯誤檢查。沒有真iPhone。
- `checks.txt`／`source-manifest.json`：本輪程式檢查、錄影邊界及原檔hash。

近鏡只是整體角色的驗收鏡頭，沒有改正常頁面人物大小。影片由真Runtime即時播放及真UI按鈕切段，沒有逐幀合成。頭頸是否自然仍須觀看連續動作，不能只看截圖或自動測試判斷。

## 驗證與限制

八項Spine測試包含頸面來源alpha、三角形連通、120Hz拉伸及臉部相對胸口轉動。刻意切除頸面三角形後，即使骨節數值正常亦應拒絕，避免重複v01漏檢。完整122檔949項測試、普通及內測構建、敘事／文案檢查通過。

錄影區段102次固定步更新回呼、最大回呼間隔259.5ms，明確有慢幀；這不是完整幀時間或GPU效能測試。沒有達到效能驗收，沒有真iPhone、溫度／耗電／長跑或TestFlight結論。不能把匯出影片標稱幀率當成遊戲實測幀率。v01的舊量測不移作本版數據。

普通構建不包含新審閱模組。內測模組含原圖及Runtime約6.23MB未壓縮，不宣稱載入改善；圖集僅無損重排為1024×2048，沒有縮素材。未執行原生Spine Editor儲存／重開／匯出，不能把可匯入JSON稱作已驗收原生`.spine`。

仍只覆蓋一頭、一衣、徒手三段；走跑、倒地起身、換裝、兵器及事件實戰尚未完成。沒有改戰鬥／耗內／回內／經濟／裝備／存檔。PR #157維持草稿，未合併、未部署、未上傳；多人及PR #156繼續暫停。
