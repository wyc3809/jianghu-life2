ui-motion.gif來自實際Chromium正常速度錄影，剪去開機／離線領受片頭，未重畫或加速人物。可見人物入頁、裝備／衣櫥冊頁、分類切換、武學及設定開關；原始影片在本機.local-online，沒有承諾影片展示所有入口。按壓只輕縮，保留朱砂／紙色，不再強制黑底或中止原動畫。頁／冊頁220–260ms，不延遲指令或結算。

## 操作驗證

checkMobileUiUx.py重跑22步，沒有pageerror或橫向溢出。checkMobileUiMotion.py以320×568、390×844、430×932檢查真正按壓、觸控拖動制服名單、modal焦點圍欄及回到入口、短屏確認／關閉可見、普通／對戰裝備與外觀／收藏不因瀏覽改變。每尺寸記錄27次真正入場事件，動畫播完及途中切換減少動態均清理；系統及遊戲內減少動態不再排動畫。motion-report.json保存度量，沒有把單張截圖當動效通過。

設定與玉石、裝備詳情入口實際高度至少44px。第一次320檢查攔到舊短屏CSS覆蓋44px，已修正選擇器後重跑三尺寸通過。其他頁面原有安全區、內容捲動與原生focus保持。觸控drag取消按壓，不攔原生手勢、不重發click。

補充真修煉／結果及掛機冊頁檢查見action-report.json。result-labels-before.jpg為本輪補查結果文字時的修正前畫面，已含共用動效與44px入口，不冒稱整張為EA0.108.0。刪除「修煉已定／披掛已定／所擇」等重複裝飾標注，保留真正行動、故事、數值與確認流程。
