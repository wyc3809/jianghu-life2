# EA0.99.1 人物手腳走樣修正

玩家指出上一版手腳錯位。本輪承認並修正實際素材合成問題；資料／操作測試通過並不足以代表人體美術正確。

## 根因與修正

EA0.99.0軀幹圖已含部分袖臂，繪圖器再疊上上臂／前臂，且盤坐只換下身，造成重複袖口、肩肘錯接及比例不合。改為每套八種完整連貫身體：待機、兩格步行、蓄勢、出招、受擊、倒地、盤坐。每次只畫一個完整身體與同款頭部，不再畫獨立手腳，亦不以縮放肢體補接。

原圖頸位、真手部握點及腳底在固定座標中映射；站立／出招沿用固定身高。頭部最後繪畫，頸位深入真領口，避免領口蓋過頸部。盤坐另用高解像完整原圖，以固定來源密度校準；人物頁／衣櫥按整幅靜態輪廓保留邊距，雙膝、雙靴不被畫布裁走。身體調色只改布色，快取上限96格，Three合成幀36格；沒有修改戰鬥數值、結果、存檔格式或獎勵。
