# 完整回合連招與難度候選驗收

2026-10-24，EA0.88.0工作分支，未發布網頁或TestFlight。對應redesign-scope第38項；iOS準備仍在獨立PR #138，本分支由正式main建立，沒有混入未發布的iOS工程。

## 行為

演武台的小兵、精英與首領共用完整回合排程。每回合選一門已裝備外功，按真正已學卷次出完：一招出卷一，三招出卷一／二／三，七招出卷一至七；只有一／三／七則只出一／三／七。多門外功按欄位逐回合輪替，無外功只作基本攻擊。敵人中途倒下即收束，不把剩餘招式打到下一個敵人。

每招依原招式威力、卷次倍率及秘笈升階計算一次傷害，動畫的多段數字只分攤該次結果；不是每段再派傷害。演武台沿用不扣角色內力的模式，沒有改事件交手的耗內、普通攻擊或冷卻規則。事件自動交手原本已串出當回合可用卷次，本次不改；華山／多人對戰與伺服器未調整。

最後一招完全收勢後才開始敵人還擊，敵人收勢後再開下一回合。首領回合號每組連招加一次，不再每招加一；卷名與七卷高亮依真招式同步。回合游標保存在現有SparDuel快取，切頁／重新掛載不免費重開連招；中途換武學先交還敵人，再用新武學開完整回合。擊倒、敗退、過關回血與獎勵由原流程處理，存檔格式不變。
