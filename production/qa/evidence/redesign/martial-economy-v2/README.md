## 難度與實用度探測

`balance-before-difficulty.json`保留首輪結果，`balance.json`為目前候選，使用真核心、固定種子，唔係真玩家統計。`catalogue-audit/audit.json`另保留103門／21小冊、21萬次抽取、七卷收集及跨派配搭篩查；抽數位移樣本並非IID玩家。

- 多人比較：6派代表武學×1／3／7卷×0／4／8境×24種子，共1296場。對手固定為相同基礎角色的三卷長河拳，用作卷數及流派差異檢查，唔代表天梯勝率。
- 事件比較：6派×1／3／7卷×0／4／8／14境×普通／強敵／首領×12種子，共2592場。首輪四境事件430／432勝，顯示原首領太弱。
- 現候選保持普通短戰鬥，強敵血量×1.35／攻擊×1.1、首領血量×1.8／攻擊×1.3；按境界使用2至4段，防守招只一段，增加拆防／虛晃／點穴，全部不足先調息，連段／特性追擊只扣一次起手。唔只加氣血拖時間。
- 四境首領72場／組：一卷1勝、三卷60勝、七卷72勝。長河拳三卷9／12勝、七卷12／12勝；普通仍適合初期獲取資源。單卷挑首領難，實際引導／可選退避及配搭成本仍需玩家試玩。七卷獲得明顯威力與內力效益，唔靠普攻拖回合。
- 演武同seed逐關、用真招式效果：零境一／三／七卷首次失敗第3／5／9關；四境第9／15／19關；八境第18／26／28關。屬單一配搭固定種子，未承諾所有流派相同關數。
- 100回合單獨回內探測：零境長河拳41起手，基礎吐納71次武學／29次調息、湧泉功80／20、太虛吐納75／25；1／3／7卷起手相同。百分比內功優勢隨上限增加，唔保證早期勝過所有固定回內。

## 未完成及發布前條件

1. **配平待試玩**：本輪已有難度候選，仍要覆核首領單卷門檻、不同外功差距、短戰鬥中回內的實用度及完整進度速度。每場滿內＋七卷同價會減少短戰鬥的缺內情況，不能單憑有回內功能就稱價值已配平。
2. **多人正式聯測未做**：服務讀取已驗證帳戶的雲端角色，挑戰前等待配搭保存，開戰再讀取雙方最近已存配搭；世界、收據與獎勵由現有CAS一次結算。本機服務／模擬儲存測試唔等於真遠端驗收。新客戶端隨機指令與後端須配合發布，唔可只推前端。源碼已兼容舊target欄位但忽略指定目標、沿用舊收據，並保留舊配搭表合法選擇；新版人物雙配搭仍優先。這些已做核心／儲存介面測試，仍需舊版TestFlight實機聯測。
3. **多裝置帳戶經濟仍有界線**：現有雲端係整份離線存檔後備，並非全部花費的伺服器錢包。累計獎勵高水位可防同一份存檔重讀收據，但唔宣稱已解決任意舊檔回滾、跨裝置同時花費或客戶端作弊；正式經濟要再完成權威錢包／交易設計及實測。
4. **舊境界證據有限**：首次遷移以本代境界及已領境界成就／家族里程碑可證明的最高下限建檔，唔補發已知舊境界；以前沒有逐境帳戶收據，無法由不存在的資料還原全部前代最高境界。未證實範圍的補領政策須先定清楚。
5. **幫會戰／門派戰未實作**：沿用第32項後續階段安排；本輪未冒稱整個多人江湖核心已齊。
6. **未上線**：沒有升版本、推分支、合併main、部署遠端或上傳Apple。需先檢視原型，再按正式發布流程處理，不能用現有EA0.90.0網頁／舊TestFlight代替本輪驗收。
