# 第58項：共用衣著造型與單線會武

玩家明確要求簡化背景、人物可選衣著造型並連接各系統。本輪目標EA0.99.0；前端發布與多人服務的實際結果見下方紀錄，沒有將正式組織戰爭當已完成。

## 實作與驗證

- 8款頭部 × 3套衣著 × 4種布色，共96種組合；免費，沒有能力或裝備加成。原圖、透明裁切、短髮越界碎片清理、映射及同圖低解像後備見 `design/art/appearance/README.md`。
- 建立人物、衣櫥、HUD、盤坐人物、演武、事件／華山／多人正反戰報及舊Three演出共用。新戰報鎖定開戰外觀；換衫不覆寫舊報，舊檔固定承接。普通／對戰裝備不受衣櫥影響。
- 116檔／909項Vitest全通過，正式公開多人開關構建與TypeScript通過；敘事hard-fail 0、口語／禁句0。見同目錄 `tests.log`、`build.log`、`narrate.log`、`copy.log`。初輪回歸找到無window環境的素材網址錯誤，已加環境守衛；戰場逐點斷言改為一次彙報所有違例，保留全幀範圍／退場檢查，沒有略過測試或提高timeout。
- 衣櫥8個瀏覽器情境：Chromium正式公開構建、WebKit開發構建，各320×568／390×844／430×932，以及全部造型網絡圖失效。真觸控、主頁固定、冊頁按鈕可見、預覽／取消無寫入、確認／連按不扣資源、兩套裝備不變、HUD一致及重開保存。正式版初次啟動的驗收腳本曾未取得續檔可點狀態，獨立定位及重跑通過，未假稱為已修正的新遊戲問題。見 `browser-report.json`。
- 建立角色另以兩引擎跑正式構建完整童年流程，選擇外觀在真正開始遊戲後保存；預覽不先建立人生。見 `creation-report.json`。
- 真正InkAutoBattle及Three元件播放固定核心產生的戰報：白髮青衫與簪髮赭紅勁裝同場，原戰報資料保持。見 `canvas-battle-390.png`、`three-battle-390.png`、`battle-browser.json`。主頁演武截圖見 `home-390.png`。
- 同場原型12情境：兩引擎三尺寸、減少動態、部分及全造型網絡圖失效；名冊20人、戰前選造型、暫停／背景／冊頁遮擋停播、恢復不追幀、跳結果／重播一致、不寫存檔、無外站請求。見 `sect/browser-report.json`。換裝與主體為新位圖骨架，所有腳點同高，實際移動也只有同一地線；站位碰撞包括出招者，避免全部疊成一團。
