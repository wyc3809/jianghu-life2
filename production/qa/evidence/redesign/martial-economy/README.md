# 第43項：抽卡／武學介面與經濟審視

基準：已發布EA0.90.0。玩家要求文字跟主頁功能頁一致，並全面檢視抽卡、武學經濟、實用度與可玩性。本次交介面原型、可重跑的核心數據及改善次序；沒有調整機率、獎勵、保底、兌換、戰鬥或舊存檔，沒有上線。

## 已做的介面修訂

- 移除舊規則強制套在武學名、實戰欄位、流派題簽及收藏名的楷字；與主頁功能頁使用同一game-ui-font。秘笈頁標題／按鈕明確粗幼，說明12px起、操作入口13px起，保留紙底墨線與朱砂筆觸。
- 池規顯示目前小冊「未觸發保底的每抽」武學／書頁、珍本及心願機率；計入直接心願與隨機抽中同一心願，不把6%條件機率當成每抽珍本機率。保底會改變下一抽／長期平均，因此不把基礎機率標成綜合機率。
- 寫明心願不保證缺卷、十連沒有額外折扣／獨立保證；收藏頁如實說明首次外功兌換整套及不能補換已藏缺卷。將通用書頁與人物殘譜分開說明。
- 人物武學標示江湖／珍本、藏本升階及原始效果，分清跨代升階與本代熟練。未學收藏不再顯示已達熟練階位／0%練習進度。裝備仍由玩家指定欄位，沒有自動學習／替換。

## 結論與優先次序

## 配搭篩查與可玩性

額外跑2,112場多人純核心對戰：12個配搭（六派各一般／珍本一門）、每個有向配對16種子、三卷、武學40／氣血400／內力200、同鐵布衫及斷橋步、熟練0／星階0／無裝備。外功只按各派可選門中最高基礎威力取樣，跨派支援固定，並非完整流派套裝測試。

一般長河樣本追風腿在自己一側的176場中勝174場；其餘有約45至143勝。此篩查足以要求擴大矩陣，不能作職業勝率榜、最佳武學排名或即時削弱依據。珍本應有玩法差異，不能只靠顏色／更高基礎威力。

現有循環可保留：選目標武學→抽取／奇遇／書頁→選欄位→累積熟練→挑戰→換配搭。缺口在「缺卷可控性、配搭成效回饋、模式一致性、長期可重做目標」，不是再加十種材料或更多抽獎入口。建議後續依序做：

1. 修正兌換語義與補卷，明確保留舊成果；先寫遷移與成本回歸。
2. 對齊四種戰鬥的快照、升階／熟練及可用效果；保留完整回合規則與非致死演武。
3. 心願補缺卷及配搭比較，讓每次進度能解釋。
4. 用真玩家首日／七日／三十日資料校準日常收益、書頁及重複出口。需要量：每種來源玉石／頁數、首個可裝備新學時間、第一門三卷／七卷時間、無武學十連後行為、兌換與升階使用率、換裝後勝率。今次沒有玩家遙測，不能聲稱已證明留存或付費表現。
