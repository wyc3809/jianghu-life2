# EA0.99.2 · 頭頸接位與多人畫面方向

玩家要求做好頭身接駁，並指出多人畫面質素低。本輪只發布共用人物接位修正；多人主構圖以三張概念圖待選，不把未驗收原型當正式模式。

## 頭頸修正與畫面證據

- 原頸底平切、空領口與膚色接位以真透明頸部材質、所選頭像取色、衣領內緣遮罩及頸底漸變處理。原圖／逐字提示／處理器及後備映射均保留。
- `neck-comparison.png` 同一霜髮劍客／江湖長衫／青玉，在相同大小、位置與原圖下比較：左欄停用新接位處理，等同原完整身體加原頭部；右欄為新處理。紅框標出頸底與領口。
- `neck-before.png`／`neck-after.png` 八款頭部×三套衣著的放大盤坐接位板。不是實際手機人物大小，不用此圖冒充手機版面驗收。
- `poses-{traveller,scholar,cloak}.png` 三套完整身體八姿勢逐格檢視。`anatomy-demo.gif` 是共用繪圖器放大實播，涵蓋待機、行走、出招、受擊、倒地與盤坐，不是玩家交手錄像。
- `neck-browser.json` 驗證面孔／下顎及深色／銀髮保護區2117331像素未被接位處理改寫（允許1階通道量化），頸底有實際變化；二十四個接位及二十四個完整姿勢已擷取，頁面錯誤0。
- `person-390.png`、`home-390.png`、`wardrobe-390.png` 為390×844、DPR2真元件畫面，按固定測試存檔生成，雲端請求隔離，不是玩家真存檔。
- `canvas-battle-390.png`、`three-battle-390.png` 與 `battle-browser.json` 是既有真自動交手元件播放：主角／對手固定所選外觀、頁面錯誤0，不改戰報或傷害。

## 多人畫面評估與範圍

先實播現有開發會武，再擷取 `01-current-formation.png`、`02-current-melee.png`。主要問題：大面積空白、二十人被壓成細排、交鋒集中、目標與招式難讀。三張獨立概念圖及逐字提示在 `design/proposals/sect-battle-review/`，按實際顯示順序編號，等玩家選定。生成圖的文字、數目與戰況只屬方向，正式實作必須用真資料與可操作元件。
