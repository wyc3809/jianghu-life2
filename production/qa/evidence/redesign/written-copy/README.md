# 全遊戲書面語與敘事精簡

玩家要求統一書面語，刪減空泛、重複或過度修飾的文字。版本維持EA0.86.0，本批未發布。

## 修改內容

介面、奇遇、抽卡、戰鬥、突破、離線收益、多人江湖、設定、雲端提示及武學／敵人說明改用繁體中文書面語。按鈕直接說明操作；規則保留成本、期限、保底與死亡風險。武俠專名、字型及素材不變。

百則事件的三百個選項名稱、六百段成功／失敗敘事逐項重寫，使行動及結果符合當前情節，不再反覆加入別的場景或感想。結果平均字數由122.5字減至18字；最短13字、最長24字，均有獨立成功／失敗文字。九類通用敘事的九十段收尾亦改為具體動作。寫作規範見`design/ux/player-copy.md`。

## 玩法與相容性

舊引擎依選項文字推導心性、關路與餘韻；顯示名稱改寫後，以固定的`mechanics_text`／`mechanicsText`保留原有推導語意。事件／選項ID、機率、效果、數值及RNG不變。新欄位屬內容資料，存檔仍只記錄原有事件／選項編號。

`choice_copy_intent.test.ts`逐一比較三百個選項：相同種子下，完整遊戲狀態、數值、旗標及RNG相同，僅遮去玩家可見文字。`semantics.json`另比對既有檔案的非文字AST，並列出人工核對的文字適配位置。沒有修改戰鬥、抽卡經濟或存檔格式。

舊後端口語在前端轉為書面語；已知認證錯誤顯示中文操作指引，未知英文錯誤使用中文後備。未修改資料庫、認證流程或部署遠端函式。既有年譜與玩家輸入文字保留；新產生文字使用修訂版。
