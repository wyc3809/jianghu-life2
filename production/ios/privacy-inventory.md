# iOS私隱資料盤點（政策草稿依據）

核對日期2026-10-24，來源為EA0.88.0真實程式。本文件未當作已發布私隱政策，也未代填App Store Connect的App Privacy。無已確認政策網址、服務聯絡電郵或保存期限，不虛構內容。

| 資料 | 去向／用途 | 現況 |
|---|---|---|
| 人物、武學、玉石、年譜及本機設定 | App的IndexedDB／localStorage，保存進度與偏好 | 離線可用；卸載可遺失 |
| 匿名user ID、session | Supabase Auth，辨識存檔與對戰身份 | 有雲端設定時啟動建立／還原身份 |
| 電郵 | 玩家綁定或登入時交Supabase Auth | 需原生登入回調與刪除方案 |
| 雲端遊戲進度 | Supabase雲端存檔 | 包含遊戲內容與人物名稱，不能聲稱沒有收集資料 |
| 榜單、名字與排行數據 | Supabase榜單，向其他玩家顯示 | 遊戲暱稱可見，不要求真名 |
| 江湖玩家快照、戰報及收益收據 | Supabase多人服務 | 依伺服器現行權限處理，刪帳需納入相關資料 |
| 網絡連線IP／服務記錄 | Supabase及字體等網絡服務可能記錄連線 | 實際保留期限須由擁有者核對服務設定 |
| 操作埋點 | 預設保留記憶體buffer，程式支援可選gtag | 未見本專案載入第三方分析SDK；若將來啟用須重審 |

`index.html`仍有Google Fonts stylesheet／preconnect；遊戲另有本機字體及後備。原生包不以Google Fonts成功載入為開局條件，但政策需交代實際外部請求；沒有宣稱全程零網絡。

目前未見廣告SDK、IDFA、定位、相機、麥克風或聯絡人用途，未新增相關權限，也未要求ATT。App及Capacitor SDK的PrivacyInfo檔案描述原生API／追蹤用途；這不代表App Privacy可以填「不收集資料」。雲端ID／電郵／遊戲內容應按Apple資料分類、與使用者關聯、用途及實際分享逐項核對。

上傳前須補：資料控制者及聯絡、收集項目、用途、處理者、公開榜單、保存／刪除期限、帳戶刪除途徑及適用地區說明。App內也須能查看已確認的政策。

帳戶刪除目前缺少App入口與後端。需要驗證本人身份、撤銷session、處理Auth／雲端存檔／榜單／多人資料，以及明確說明依法保留的例外。不能只清localStorage、只登出，或要求在聊天交admin key。未完成前保留為發布前缺項。
