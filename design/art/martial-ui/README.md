- 新原創玉紋：`public/ink/art/token/jade.webp`，512×512 RGB、5,646bytes。`scripts/art/build_token_jade.py`固定seed81／82／83，離線生成多尺度水彩礦物雲紋及淡玉脈；不含外部圖片、文字、水印、假alpha或SVG。
