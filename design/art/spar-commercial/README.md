## 接入規格

- 122個遊戲WebP，共3,547,354 bytes：共用四季／主角／特效1,623,928 bytes；25款倒地按當前敵人逐款載入，唔一次下載100張。
- 主角步行邏輯尺寸900×800du，腳底788du；敵人倒地1800×800du，實際輸出540×240，腳底788du。實際像素尺寸同設計座標分開，適合手機DPR2角色尺寸。
- 石台腳底固定舞台高度84.5%，唔對石台呼吸縮放；動態只有AI霧位圖、天氣位圖、角色與交手效果。

- 換季0.6秒交疊；沿用同一Canvas搬入全屏首領，唔另起戰鬥。
- 純畫面RNG獨立seed；天氣RNG同人物／交手抽樣分開，唔影響核心遊戲RNG。
- 減少動態：保留原有慢速對練，關閉天氣、流霧移動、震屏、塵土、刀光及爆點，保留地面／陰影／字及戰鬥結果。
