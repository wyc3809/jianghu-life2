## 1. 一句話

**沉實古韻，金石為框，人物為主。**

- 似一部江湖畫卷入面嘅人物，唔係一張網頁表格。
- 人物立繪同場景佔大部分畫面；資訊用漆木牌、古銅框、印章浮喺上面。
- 色彩沉實（墨、土、古銅），用朱紅同青綠點睛。

## 2. 色板

| Token | Hex | 用法 |
|---|---|---|
| `--b-lacquer` | `#1E1814` | 漆木深底（面板、底欄） |
| `--b-lacquer-2` | `#2E241D` | 漆木次層、分隔 |
| `--b-wood` | `#5A4334` | 木框、邊條 |
| `--b-bronze` | `#B8913E` | 古銅金：框線、花紋、重要數字 |
| `--b-bronze-hi` | `#E3C46A` | 金高光、按下狀態 |
| `--b-parchment` | `#E9DFC8` | 舊紙卷軸內文底 |
| `--b-ink` | `#1C1A17` | 卷軸上嘅正文 |
| `--b-text-on-dark` | `#EFE6D0` | 深底上嘅正文 |
| `--b-cinnabar` | `#A8342A` | 印章、危險、主要按鈕 |
| `--b-jade` | `#3F6670` | 青綠：次要按鈕、玉石、內力 |
| `--b-mist` | `#8C8A82` | 遠山霧、停用狀態 |

**規則**
- 深底面板（漆木）同淺底卷軸（舊紙）兩種，唔好混用第三種底色。
- 一個畫面入面，古銅金只用喺框同重點數字，唔好成片金色。
- 朱紅只用喺主要按鈕、印章、警告。

## 3. 字體

| 用途 | 字體 | 備註 |
|---|---|---|
| 標題、地名、招式名 | 書法體：Ma Shan Zheng（Google Fonts，免費商用） | 大字、加古銅描邊或陰影 |
| 正文 | Noto Serif TC（思源宋體） | 卷軸上用墨色，深底上用 `--b-text-on-dark` |
| 數字（血量、傷害、貨幣） | Noto Serif TC 粗體，加深色描邊 | 傷害數字可加漸層 |

## 5. 人物

- **畫風**：半寫實古風厚塗，正常比例（唔係 Q 版、唔係大眼國漫）。
- **光線**：左上主光，背光邊緣有柔和輪廓光。
- **服裝**：按門派分色（武當青白、少林赭黃、峨嵋素紫、唐門墨綠等），布料有層次同刺繡。
- **用途**：
  - 主角立繪：主畫面、人物頁
  - NPC 半身像：事件、奇遇
  - 首領立繪：登場卡
- 演武台同自動戰鬥仍然用剪影（第 20 項），唔強求立繪。

## 6. 場景

- 寫實水墨山水：近景清楚、遠景霧化，有三層以上嘅遠近。
- 時間同天氣分色調：日間暖灰、夜間藍墨、雨天青灰。
- 主畫面場景要佔滿畫面寬度，唔好再框喺細框入面。

| 類別 | 尺寸 | 背景 |

| 立繪 | 直幅 2:3，至少 1024×1536 | 透明或純色（之後去背） |
| 半身像 | 1:1，至少 1024 | 透明 |
| 場景 | 9:16 直幅，至少 1080×1920 | 完整場景 |
| UI 框、按鈕 | 按部件，至少 2 倍顯示尺寸 | 透明 |

## 8. 禁止

- 冇角色嘅純文字大畫面（主畫面一定要有人物或者場景）
- 網頁式表格同虛線格
- 原生下拉選單外觀（要包成遊戲風格）
- 紫色霓虹、科幻光效
- SVG（PWA icon 除外）
