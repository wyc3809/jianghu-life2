# 明亮漫畫宣紙 · EA0.112.0

玩家明確要求開卷及人物等背景太深，改為貼近現有完整漫畫立繪並統一藝術風格。本輪選明亮象牙紙、淡青山水、少量桃色草木、清晰墨字與朱砂主操作；繼續使用原有漫畫人物、器物牌章及斗笠黑影戰鬥。

共用底圖為1024×1536直幅，中央大幅留白，山水與植物集中邊角，前景淡石坪；不烘文字、人物、按鈕或框。image_gen以原人物頁山水作構圖參考重新生成1張日景；source.png保留原生成檔與嵌入metadata，原工具檔亦留在workspace/generated_images。runtime僅轉WebP（134,300 bytes），未裁切、拉伸或改色；來源hash、權利註記及檢查狀態見manifest.json。

開卷用既有霜髮／旅裝／青玉完整立繪作裝飾封面，黑色毛筆題字、直排卷首與朱砂主鍵；封面不寫入／更換玩家造型。新遊戲及續寫沿原回調，無存檔仍只顯開卷。人物及創角、人物誌、衣櫥／武學卡片、修煉、秘笈等共用淺紙材質；人物誌橫幅讀真造型。舊夜景素材保留，不再作這些頁面的全屏底。

材質與頁面由src/components/ink/art-theme.css統一：底紙#fffaf2、正文#25241f、淡青／桃色作環境、朱砂沿既有ui-red；paper／ui-fiber／ui-card保持共用，舊纖維及卡片加半透明淺紙層。夜間事件保留夜雨語境／標記，底紙仍明亮；季節、場所、天氣粒子及戰鬥場景不改玩法。江湖地圖只降低底圖不透明度、保留原圖及四地標座標，朱砂小點取代金光。

同色延伸至瀏覽器theme-color、PWA與iOS WebView／LaunchScreen；原生可安裝與硬件體驗仍須新TestFlight，不把瀏覽器或Mac Archive當真iPhone驗收。後續頁面沿用共用材質，避免再加入黑金封面、深灰滿底或整體泛黃／壓暗濾鏡。
