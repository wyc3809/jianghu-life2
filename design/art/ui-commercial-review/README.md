## 出資方判斷

若交付要求係「完整、可正式推出嘅商業遊戲」，目前未達可收貨標準；若係已實現核心玩法嘅可玩原型，具備後續打磨基礎。金額 1,000,000 本身不足以判斷成本合理性：幣種、合約交付範圍、工期、人手、授權、內容量與營運承諾未提供。以下只評估現有介面與可驗證交付，不作成本審計或營收保證。

本次已重新開啟實際遊戲，用 seed 42、已完成新手、600免費玉石、演武台第1關，390×844／2倍像素截圖。

## 觀察與改善

| 觀察 | 改善 | 驗收證據 |
|---|---|---|
| 頭像姓氏、設色圖示、墨筆條、文字按鈕嘅製作質感未統一 | 固定色板、材質、線條、光源、字體階層與按鈕規格 | 主畫面／人物／秘笈閣／設定四頁同樣規格 |
| 當前目標、收成及過月各有資訊，未有足夠清楚嘅優先次序 | 保留功能及原演武台位置；目標寫明下一步，收成用清楚可按狀態，過月保持既有意義 | 玩家能辨認下一步及兩種操作嘅差別 |
| 收益區有虛線、多欄細字、單位換行 | 可讀數字＋短標籤；詳細規則仍可查看，避免截走原資訊 | 320／390／420px；所有數字、單位不重疊 |
| 有特效，但每個互動需有一致狀態與回饋 | 定義普通／按下／不可用／處理中／成功／失敗；成功後餘額與按鈕同步 | 連點、零餘額、延遲、退出重入皆可驗證 |
| 單靠截圖無法驗證完成度 | 動態GIF、手機操作、低效能與減少動態驗證 | 真實操作錄影及測試紀錄，不能拿AI概念充當實作證據 |

## 兩個待選方向

- **A（建議）淺色水墨精修**：保留姓氏頭像與既有辨識度，統一圖示、字體及材質，突出目標／收成。
- **B 淺色設色武俠**：人物頭像、器物設色、掛軸質感較豐富；實作會控制裝飾密度。

`concepts-a-b.png` 係 AI 概念，唔係遊戲截圖，亦唔係可直接嵌入嘅單張介面。中文字有偏差，全部動態文字會由真實UI呈現。圖中演武台只用作示意；現行引擎、場景、尺寸、位置、操作及玩法不因概念而改動。概念省略咗部分詳細資料，實作不能因此刪功能，需保留其入口／內容。B圖中季節裝飾未獲認可，不可直接套用。

## 製作與交付次序

1. 玩家揀A或B，確認主畫面樣板範圍。
2. AI生成可分開用嘅圖示、材質及肖像素材；檢查透明邊、比例、縮小後辨識度、風格一致性。中文字不烘焙進圖片。
3. 只落地一頁可操作樣板。沿用原store及動效入口，不修改經濟數值、存檔或演武台。
4. 提供改前／改後對比、紅框、情境、GIF及320／390／420px操作證據，玩家確認。
5. 確認後逐頁擴展人物／武學／秘笈閣／奇遇／結果／設定等，避免一輪重寫全遊戲。
6. 實作後跑全部Vitest、build、audit:narrate；真實手機與低效能回歸另列未驗證項目。再次收到發布指示先上線。

## 建議驗收門檻（待玩家確認，唔係已達成）

- 5位首次接觸玩家中，至少4位能在10秒內指出下一個目標及操作；10分鐘內自行完成挑戰→獎勵→換裝→再挑戰。用真實觀察記錄，不冒充已有數據。
- 常用可按區以至少44 CSS px為Web樣板起點；不重疊、不被導航遮擋，實機再驗證。
- 動態只服務狀態與獎勵，不能強制長時間阻塞重複操作；減少動態仍見結果。
- 確認目標Android與iPhone之後量測幀時間、載入、記憶體及輸入延遲；未做實機不能承諾60fps。
- 所有現有功能都有可達入口；無缺字、錯字、透明邊污染、素材糊化、數字跳版、無故紅點。
- 正式收貨另需內容完整度、雲端換機、資料安全、付費（本版未開）、留存／營運及授權驗收；靚UI唔代表全案完成。

## 可操作樣板交付（2026-10-11）

玩家已要求「可以做 俾我睇吓A定B」，兩款主畫面樣板已實作；仍未揀正式方向，未發布。

啟動 `npx vite --host 127.0.0.1 --port 5175`：
- 原版：`http://127.0.0.1:5175/`
- A：`http://127.0.0.1:5175/?ui-preview=a`
- B：`http://127.0.0.1:5175/?ui-preview=b`

`ui-preview`只喺開發版生效；正式構建與無參數入口沿用原版。兩款共用AI位圖圖示；A較克制，B較設色，並使用一張示意肖像。B肖像係樣板美術，未按角色性別／年齡／外貌變化，正式使用前要另定角色頭像規則。

實作只涉及樣板入口、快捷圖示及獨立樣式；演武台、遊戲數值、存檔、雲端與抽卡規則無改。收益區改成兩項主收益＋一行演武收益，三項資訊均保留；收成仍係原有真實store action。原版快捷入口及底部導航完整保留。

驗證：570個測試通過（包含正式環境不啟用樣板、開發入口、錯誤参数回原版）；build、audit:narrate通過。390px量測兩版演武台與原版均為 x=10、y=169.40625、370×230 CSS px；320／420px無橫向溢出，兩版實際收成／秘笈閣／設定入口及減少動態另附操作驗證。截圖字體使用環境現有Noto Sans CJK作對比板標題；附件指定嘅文泉驛字體路徑不存在。原始遊戲截圖本身未修改。
