# 多人江湖第一版：已確認規則與原型範圍

日期：2026-10-20。狀態：已確認規則嘅本機雙帳戶原型已實作，待玩家睇實際畫面；未部署。玩家決定總記錄見 `production/redesign-scope.md` 第32項。

## 玩家已確認

| 項目 | 規則 |
|---|---|
| 在線 | 選對手、配搭武學，自動逐招；獎勵明顯較高 |
| 離線收益 | 關閉遊戲後累積少量收益，再上線領取 |
| 離線交戰 | 角色留場，由系統自動應戰，其他玩家仍可襲擊 |
| 戰敗後果 | PvP唔造成傷勢、死亡或接班；只按排名規則處理 |
| 名次 | 較低排名打贏較高排名先直接互換，其他玩家不變 |
| 挑戰失敗 | 較低排名挑戰高排名失敗，雙方名次不變 |
| 戰敗保護 | 短暫不能被襲擊，主動出擊解除；時長待定 |

例：100名勝20名，雙方變20／100；100名輸畀20名，維持100／20。未批准積分制、依次順延、掉落裝備／資源或即時手動走位。原有人生及PvE傷亡規則不變。

## 本機原型（玩家2026-10-21確認先做）

兩個獨立帳戶，展示在線／離線狀態、對手選擇、自動逐招、同一戰報、排名互換、失敗不變及戰敗保護。使用隔離測試角色，保護時長／收益等未定值只作明示測試參數。

伺服器驗證身份、讀可信角色快照及裁決，客戶端只提交動作並播放結果。重送、重播、切頁／斷線唔可以重複換位或派獎；同一角色同時交戰要有一致性控制。既有本機存檔唔直接成為可信多人數值。
