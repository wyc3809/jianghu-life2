# 鎮居演武台（v4）

> 程式：`src/spar/v4/`（`director.ts` 節奏、`renderer.ts` 畫面、`look.ts` 連動、`SparView.tsx` 元件）· 入口：`src/components/ink/InkSparStage.tsx`
> 數據：`data/spar/clips.ts`（動作表）、`data/spar/tuning.ts`（參數）、`data/spar/anchors.generated.json`（手位、兵器角度、紅眼位）
> 素材：`public/ink/spar/v4/`（由 `scripts/art/build_spar_v4.py` 出佔位圖）· 示範頁：`?fx=spar`
> 測試：`tests/spar_v4_director.test.ts`

## 畫面

- 2D 點陣分層逐格 WebP，冇 SVG，唔用 canvas 路徑剪影。宣紙淡彩設色，濃墨乾筆外輪廓。
- 側面構圖：主角企左面向右，敵人由右邊出場面向左；一次一個。
- 演武台填滿鎮居頁標題同底部選單之間嘅空位（最矮 210px），人物同地面按舞台比例縮放。
- 背景三層（遠山、地點特色、近景草石），主角行路時世界捲動，三層以 0.12／0.4／1 倍速移動做視差。背景跟地點換（鎮、河、山、館、野）；季節飄落物（春花瓣、夏螢火、秋落葉、冬雪）畫喺人物後面。
- 鏡頭固定：唔推近、唔跟人、唔震屏、唔停格。

## 節奏（`SPAR_TIMING`、`SPAR_BOSS`）

| 階段 | 長度 | 內容 |
|------|------|------|
| next | 0.4 秒 | 新敵人墨暈化出 |
| walk | 1.0 秒 | 主角行路，世界捲動令敵人埋身到射程 |
| windup | 0.3 秒 | 蓄招 |
| strike | 0.2 秒 | 揮擊：墨痕刀光寫出、命中叫 `sparStrike()` |
| recover | 0.6 秒 | 收勢，敵人潰散化墨點 |

- 一個小兵約 2.5 秒；小兵一擊即倒。
- 每 15 個小兵出一個頭目：strike（第 1 擊，受擊）→ combo（第 2 擊，受擊）→ ultimate 大招（第 3 擊，潰散）→ recover；頭目之後重新計數。
- 撳敵人（walk／next 期間）：dash 0.14 秒衝前，唔蓄招直接揮擊；交手中撳無效。
- 每一擊照舊叫 `store.sparStrike()`，唔改任何數值。

## 打擊感

- 墨痕刀光：兵器款式決定筆觸（劍＝弧、刀＝重弧、槍／弓＝直刺、棍＝大圓弧、空手／暗器＝短撇、大招＝大撇），由左到右寫出（前 40%）再淡走。
- 命中點：墨花 `fx-splash.webp`＋墨點（頭目加朱砂點）。
- 聲：梆子＋堂鼓（小兵）、加重（頭目）、加鑼（大招）；出手有破空擦弦聲。手機輕震／中震／重震，跟遊戲設定；玩家未撳過畫面之前唔震。
- 「+N 修為」：墨字喺命中點彈起（0.35 秒）再沿曲線飛落底部修為圈（0.7 秒），到位時修為圈跳一下；頭目用朱砂字。

## 同遊戲狀態連動（`look.ts`）

| 遊戲狀態 | 表現 |
|----------|------|
| 門派 | 袍色（無門派＝浪人本色麻） |
| 裝備兵器 | 兵器圖層、射程、刀光款式；冇就空手 |
| 裝備護甲／飾物 | 護肩護胸層／玉佩層 |
| 修為境界 0–6 | 敵人等級 1–6（6 同 7 境共用最高級），越高越大隻、兵器越重；頭目加朱砂腰帶、肩甲、披風 |
| 腳傷（或 limp 狀態） | 跛行動作 |
| 手傷 | 待機掩住手 |
| 頭／身重傷 | 微微弓身 |
| 流血類狀態 | 腰間滴朱墨，落地化開 |
| 地點 | 背景（`placeToInk`） |
| 月份 | 季節飄落物 |
| 身上狀態 | 左上角標籤（照舊） |

## 減少動態、省電

- 減少動態：行得慢啲（0.6 倍速）、冇飄落物、冇滴血、墨點減到 4–6 粒、紅眼唔脈動；刀光、飛字照有（飛字改原地淡出）。
- 演武台捲出畫面就停止更新同繪圖。

## AI 真圖替換清單

佔位圖全部由 `python3 scripts/art/build_spar_v4.py` 出（約 5 分鐘；`… fx bg` 只重出刀光、飄落物、背景）。
AI 真圖**同名同尺寸**放返同一位置即可，程式碼唔使改；如果姿勢同佔位圖唔同，要同步改 `anchors.generated.json` 入面嗰格嘅 `hand`（手位）、`angle`（前臂角度，弧度）、`eye`（紅眼位）。

- 設計格 320×400（圖像 ×1.5＝每格 **480×600 px**），透明底，橫排條圖，每格等寬。
- 腳底錨點：主角 (120, 388)、敵人 (200, 388)（設計座標），所有格一致。
- 風格：宣紙淡彩、低飽和礦物顏料、濃墨乾筆外輪廓帶飛白；冇五官（斗笠下淡墨陰影）；敵人蒙面、留紅眼位（紅眼由程式畫）。
