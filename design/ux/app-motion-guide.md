# App動畫與試煉換裝引導：第一批

2026-10-30；玩家同意先完成動畫啟停／預載／自動畫質，以及試煉至比較換裝引導。沿用Capacitor、Three.js／GSAP及既有宣紙／朱砂／毛筆系統，不重寫整個遊戲。

## 動畫

`src/ui/visualActivity.ts`統一前景、離屏、高光遮蔽、原生視窗及減少動態通知。純裝飾Canvas停止時取消RAF，返回首幀dt為0；解除所有監聽，已離場物件不再重開。

- 環境墨塵：被遮住／離屏／背景／減少動態時停循環及清畫布，無逐幀空輪詢。
- 秘笈閣待機書冊：原生冊頁或高光遮住時停循環，關閉恢復；保留靜態後備、材質補畫及context清理。
- 演武台：離開原homeVisible狀態／離屏／背景時停止無用循環，恢復重設首幀。高光覆蓋仍按原規則推進引擎、略過繪畫，沒有改戰鬥、派獎、離線收益公式或速度設定。
- 高光Director：背景時暫停自己的主時間線、待機、延遲、DOM與代理物件動畫，取消RAF及蓄力長音；返回接續。揭曉與飛幣由ownAnimation登記，離場取消延後回調，避免舊演出再ack新時刻。不暫停GSAP全局ticker。

三種主高光及丹爐共用`HighlightRenderBudget`。連續三幀超42ms先減粒子至0.65，再三幀至0.4，持續慢幀才沿原門檻降低3D DPR至最低0.8（低DPR裝置不升超自身上限）；DOM文字／結果卡不受影響。靜止結果恢復原DPR，只按需要補畫。真正前後景切換明確重設連續幀歷史；連續超過一秒的可見慢幀仍計入降質，避免軟件GPU／錄影時永遠保持高DPR。這是視覺參數，不是新玩法數值。

前景閒時按將進入的功能預載模組／材質；背景或離場取消排程，失敗不阻止正常載入。自動交手的重模組不再隨每次開局一併預載，仍在使用時lazy載入。此批沒有新增常駐隱藏WebGL舞台或宣稱跨context著色器已預編譯，冷啟GPU編譯仍需真機量度。

## 引導

真試煉 → 領取原兵器 → 前往人物 → 點武器欄 → 選候選兵器 → 比較／可取消 → 確認換上 → 顯示真兵器攻擊前後值 → 返回鎮居看交手及下一個突破目標。

`core/life/newbieGuide.ts`只讀現有新手旗標、持有物及裝備，不抽取、不派獎、不推RNG。主頁任務「前往人物」取代直接換上；試煉所得的舊比較詢問亦可前往人物，先收好原物，未確認不換裝。其他掉落比較維持原流程。比較前沿用ensureNewbieReward修復仍在新手階段、已贏試煉但遺失兵器的舊檔；只補該件已得物，不自動換裝、不重派銀兩或其他獎勵。未贏試煉或已完成者不補。

人物武器入口用既有朱砂位圖選框提示，視窗內標記試煉所得兵器；不強制選中、不代按確認。成功普通配搭換上後，保存當次原兵器攻擊旗標，顯示「兵器攻擊4→10」等真資料，不把它當成角色總攻擊。對戰配搭不算完成普通引導；沒有持有物不假稱已取得。

略過沿用coach_done，重開只清除此提示旗標，保留真正新手／任務進度及帳戶領獎收據。設定有目前提示及基本操作說明；已完成者不強迫重做，舊檔／後代沿原規則。原「圓鈕／甲乙丙」文字改成現有操作。一般30、重要120等獎勵與門檻不變。

提示套用共用紙纖維、磨邊及毛筆；題字子集補掃core的可見文字，保留原OFL來源及重建腳本。全屏人物不加上下導覽；手機觸控保留44px，只有背包格捲動。
