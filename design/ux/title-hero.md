# 主頁動畫：3D 水墨斗笠劍客

> 程式：`src/fx/highlight/title/`（`swordsman.ts` 模型、`titleDirector.ts` 導演、`TitleHero.tsx` 圖層）· 主頁：`src/components/ink/InkStartScreen.tsx`
> 示範頁：`?fx=title`（`&resume=1` 顯示續寫按鈕、`&slow=0.2` GSAP 放慢逐格睇、`&still=1` 透明底淨劍客，用嚟重截後備圖）
> 決策：沿用 ADR-002（Three.js＋GSAP 只喺 `src/fx/highlight/`，lazy chunk）；渲染器、粒子、音效同高光時刻共用。

## 畫面

- 底：霧山宣紙圖（`backdrop-result-mist`，山峰置中，劍客企喺峰頂）＋紙紋＋四邊淡墨暈。
- 劍客背後：泥金淡光（只由輪廓邊溢出）、兩層慢轉淡墨環（`ink-halo-a/b`）、腳下淡墨投影。
- 題字：霞鶩文楷 TC 逐字落墨（化開 → 收實），朱砂「人生初度」印蓋落；卷首三句直排喺劍客左邊（逗號改空格，逐字 span）。
- 按鈕：朱砂筆觸主按鈕／淡墨框次按鈕（沿用統一元件）。

## 劍客（真 3D，全部幾何拼出）

| 部件 | 結構 | 動作 |
|------|------|------|
| 斗笠 | 有厚度嘅錐（上下兩面＋圓邊）、16 條竹篾骨、竹圈包邊、頂鈕 | 頭輕擺 |
| 垂紗 | 開口圓筒，直褶、下擺參差，前面開縫見淡墨陰影面（冇五官） | 越落越擺，受風揚起 |
| 上衣 | 車床身形、交領兩條領緣、內衫三角 | 呼吸（胸口微脹） |
| 腰帶 | 朱砂帶、帶結、兩條垂帶 | 垂帶隨風擺 |
| 玉佩 | 繩、玉環、流蘇 | 輕晃 |
| 長袍 | 有厚度嘅開衩下擺、弧形包邊、開衩直包邊 | 蹲低時壓扁 |
| 披風 | 背後弧形網格（22×16），向下擴開 | 逐格頂點受風，一波一波，陣風時鼓起 |
| 手臂 | 闊袖、袖口包邊、手 | 右手搭劍柄、拔劍、向外平揮 |
| 劍鞘 | 鞘身、鞘口／中箍／鞘尾泥金 | 左手斜握 |

著色：MeshToonMaterial 4 階（暗部收淡成淡墨暈）＋主光、天光、泥金輪廓光。描邊：後期法線＋深度邊緣（濃墨外輪廓帶飛白、淡墨內線），1.5 倍超採樣＋MSAA；法線 pass 雙面，垂紗、披風呢類薄片外輪廓唔會漏。

## 節奏（時長）

| 階段 | 時長 | 內容 |
|------|------|------|
| 開場 | 約 1.3 秒 | 題字逐字落墨（每字 0.62 秒、間隔 0.12）；0.75 秒蓋印（0.5 秒回彈）；副題 0.7 秒、直排三句 0.95 秒淡入 |
| 待機 | 循環 | 左右轉 ±0.38 弧度（一個來回 4.4 秒）、呼吸 1.9 秒、每約 4.6 秒（±20%）一陣風：0.55 秒揚起 → 1.7 秒回落，墨點金箔由左吹過 |
| 1 蓄勢 | 0.36 秒 | 轉正、蹲低、右手搭劍柄、披風收；墨點由四周吸入（到輪廓外即消失）；擦弦漸升 |
| 2 拔劍一揮 | 0.26 秒 | 劍轉去右手，向外平揮出弧；劍尖逐幀留墨痕；木魚一聲 |
| 3 爆開 | 0.14 秒停頓（效果延續約 0.55 秒） | 劍客背後亮紙（≤0.8）、三道墨環（中間一道朱砂）由輪廓外擴、墨點由輪廓邊噴、墨痕、金箔；震屏 0.34 秒、鏡頭推近 0.16 秒；大鼓＋鑼 |
| 4 紙面化開 | 0.44 秒 | 宣紙由胸口圓形暈開蓋滿畫面 → 入下一頁 |

過場合共約 1.2 秒；標題、直排字、按鈕喺過場開始 0.22 秒內淡走，讓劍客獨佔畫面。過場中撳任何位置或 Esc 即跳過。

## 版面

主角按「標題同按鈕之間嘅空位」（`.ink-start-slot`）定位：高度＝空位 × 0.9（上限畫面 44%），中心＝空位中心；窄屏再確保闊度唔出界。靜態後備圖放喺同一空位（top 5%、height 90%），所以 3D 載入後淡走時唔會跳位。

## 減少動態（`prefers-reduced-motion` 或遊戲設定）

- 撳開卷直接入下一頁，唔播過場（冇震屏、冇閃、冇粒子）。
- 待機轉身幅度打 3 折；陣風細啲、唔吹墨點；粒子密度 35%；唔超採樣。
- 淡墨環停轉；題字、印章唔做落墨動畫。
