# 外功專屬動畫（第 25 項）

## 1. Overview

每套外功有自己一套出招動畫，按功夫名設計動作同特效，喺演武台同自動交手（3D 同 2D 後備）都會播。
同一套外功七卷共用同一套動畫；唔同外功之間動作要真係唔同，唔可以淨係換顏色或者換圖形（玩家 2026-10-14）。
動畫只係演出：傷害、命中、勝負照舊由戰鬥結算決定。第一批先做 8 套樣板，玩家確認方向之後再做其餘外功。

## 2. Player Fantasy

學到一套新外功，一出手就認得出係邊套：長河拳一浪接一浪，驚雷刀躍上半空借雷劈落，珍瓏棋局喺敵人腳下佈棋局。
收集武學唔再淨係數字變大，而係睇得到自己學咗乜。

## 3. Detailed Rules

- **出邊套**
  - 自動交手：每回合用嗰招外功（replay 嘅 `skillId`）就播嗰套動畫。
  - 演武台：主角輪住用已學外功（主修排第一，之後按學識次序），每招換下一套。
  - 未有編排嘅外功、普通攻擊：照用原本揮擊動畫。
- **編排內容**（`src/fx/art/recipes.ts`）
  - 主角軌：位移（衝前、後撤、跳起、穿過敵人）、轉身、拉長壓扁、閃現（透明）、姿勢（待機／蓄勢／揮擊／行路）。
  - 敵人軌：被推後、拋上半空、壓扁、困住。
  - 命中事件：分幾段，每段佔總傷害比例（加埋＝1）；重擊會震屏、停格。
  - 特效事件：位圖粒子（水浪、地裂、雨絲、雷、雲、飛針、風、棋盤棋子等），可以飛向敵人、跌落地、跟住敵人。
  - 鏡頭事件：震屏、白光、天色轉暗、停格、慢鏡。
- **第一批 8 套**

| 外功 | 動作 | 招牌特效 |
|---|---|---|
| 長河拳 | 三下崩拳一浪推一浪，敵人逐步被推後 | 水浪、巨浪、水花 |
| 裂石殘掌 | 蹲身躍起一掌拍地，敵人被碎石拋起再跌落 | 地裂、碎石、塵 |
| 聽雨劍意 | 靜立聽雨，閃現敵前連刺三劍，再閃返原位 | 雨絲、雨珠、劍光 |

| 穿雲槍 | 後撤聚氣，一槍貫穿敵人衝到敵後，慢鏡 | 聚氣、槍芒、雲團、雲洞 |

- **素材**：全部位圖（`public/ink/art/artfx/`，`scripts/art/build_art_fx.py` 生成），唔用 SVG。AI 圖可以同名同尺寸替換。
- **減少動態**：唔震屏、唔白光、唔轉暗、唔停格，粒子減半；位移照播（動作本身係資訊）。

## 4. Formulas

```
主角位置 x = 原位 + x(H) × 身高 + g × 主角到敵人距離      // g＝1 貼到敵人身前；>1 穿過敵人
主角位置 y = 地面 + y(H) × 身高
每段傷害   = floor(總傷害 × share)；最後一段補尾數            // 加埋一定等於總傷害
演武台敵人計時：招式時間 t > 0.72 秒（原本揮擊長度）就暫停    // 動畫長咗都唔會令演武難度改變
```

例：聽雨劍意總傷害 100，三段 share 0.33／0.33／0.34 → 彈 33、33、34。

## 5. Edge Cases

- 落空（傷害 0）：照播動作，唔彈數字，3D 顯示「落空」。
- 第一段已經打死敵人：敵人等到最後一段先倒地，數字照分段彈。
- 主角喺演武台招式途中倒地：招式即刻中止，照舊倒地重來。
- 招式途中敵人換人（演武台）：之後嘅命中打而家最前嗰個敵人。
- 加速 ×2、停格、慢鏡：3D 用 GSAP 推編排時間，全部自動跟住。
- 特效圖未載好：嗰粒特效唔畫，動作同數字照舊。

## 6. Dependencies

- `src/fx/art/choreo.ts`（編排格式、取樣、分段傷害）、`recipes.ts`（8 套編排）、`fxLayer.ts`（位圖特效層）
- `src/spar/engine.ts`（演武台、2D 自動交手後備；`SparCombatHooks.nextArt`）、`src/spar/artCycle.ts`（演武台輪替）
- `src/fx/highlight/duel/director.ts`（3D 自動交手）
- `core/life/autoCombat.ts`（replay 帶 `skillId`）
- `design/gdd/spar-duel.md`：演武台嘅出手節奏同難度；呢度只改演出，難度唔變
- 外功七卷（`content/martial/volumes.json`）：卷數唔影響動畫

## 7. Tuning Knobs

全部係測試參數：

- 每套編排嘅時間、位移、命中分段、特效大細（`src/fx/art/recipes.ts`）
- 演武台特效放大 `artFx.sizeMul` 1.5（人物細，特效要大啲先睇得清）
- 演武台敵人計時暫停門檻：原本揮擊長度 0.72 秒（`SPAR_CLIPS.attack.dur`）
- 3D 震屏換算：編排 amount × 0.025 世界單位
