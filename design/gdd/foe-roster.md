# 敵人圖鑑與首領特性（第 20 項）

## 1. Overview

演武台同自動戰鬥共用一份敵人圖鑑（`data/foes/roster.ts`）。演武台 6 個場景各係一個地區，每區有小兵、2 個精英、1 個首領。
每個首領有一個特性（`data/foes/traits.ts`），同區精英用同一個特性但數值弱化。特性喺演武台（`core/life/sparDuel.ts`）同事件交手（`core/life/combat.ts`，包括自動戰鬥）都生效，而且一定要喺畫面上睇得到。

## 2. Player Fantasy

一入新地區，就知道呢度係邊路人馬。精英一出場有金邊、有特性光環，玩家會諗：「首領應該都係呢招，而且仲勁啲。」
到首領出場，有朱砂邊、名號同登場卡，特性一觸發就彈出特性印，一眼睇得出佢做咗咩。

## 3. Detailed Rules

**層級**

| 層級 | 特性 | 外觀 |
|------|------|------|
| 小兵 | 冇 | 墨色剪影，衣帶有地區點綴色，紅眼 |
| 精英 | 地區首領特性（弱化） | 金色描邊、淡特性光柱、名牌寫「精英」 |
| 首領 | 地區首領特性（全力） | 朱砂描邊、濃特性光柱、名牌寫「首領」、事件交手有登場卡 |

**地區同特性**

| 地區 | 主題 | 首領（名號） | 特性 |
|------|------|--------------|------|
| 千燈鎮 | 市井潑皮 | 鎮上惡霸（鐵肚金剛） | 鐵布衫：受傷減少 |
| 山道 | 山道劫匪 | 赤髮寨主（開山赤鬼） | 開山蓄力：每幾擊一記重擊 |
| 竹林 | 影門殺陣 | 影門門主（噬血竹魔） | 噬血：打中你就回血 |
| 雨夜客棧 | 夜行刺客 | 鐵面影魁（千影） | 分影連擊：有機會多打一擊 |
| 山門 | 邪寺頭陀 | 鬼面頭陀（金剛鬼面） | 金剛反震：打佢會被反震 |
| 夜山 | 黑風寨 | 黑風寨主（黑風狂獅） | 狂怒：半血以下攻擊大增 |

**每關出場次序**：小兵 → 精英 → 首領。每個場景 10 關：第 1–2 關冇精英，第 3–6 關 1 個，第 7–10 關 2 個。

**事件交手身份**：
- 圖鑑有個名，就用圖鑑嘅層級同特性。
- 圖鑑冇個名：`boss` 當首領，`strong` 當精英，其他當小兵。
- 精英同首領按名字揀剪影，再借用同剪影地區首領嘅特性。

**視覺**（演武台、自動戰鬥 2D 後備、3D duel 三個畫面一致）：

| 特性 | 觸發時 |
|------|--------|
| 鐵布衫 | 敵人頭頂彈「卸」 |
| 金剛反震 | 主角身上彈「震」，加紅色扣血數字 |
| 開山蓄力 | 出手前光環暴漲、收細嘅特性色環，名牌跳動；出手時彈「蓄」，加震屏 |
| 噬血 | 彈「噬」，加綠色回血數字 |
| 分影連擊 | 彈「連」 |
| 狂怒 | 彈一次「怒」，之後身後一直有墨紅火舌 |

## 4. Formulas

設：`dmg` 為未計特性嘅傷害，`v` 為特性數值（首領／精英各一組，見第 7 節）。

| 特性 | 公式 |
|------|------|
| 鐵布衫 | `taken = dmg − min(dmg − 1, round(dmg × v))` |
| 金剛反震 | `reflect = round(taken × v)`；主角最少留 1 點血 |
| 開山蓄力 | 第 `n` 擊，當 `n mod every = 0`，攻擊 ×`v` |
| 狂怒 | 當 `hp / maxHp ≤ 0.5`，攻擊 ×`(1 + v)` |
| 噬血 | `heal = round(dealt × v)`，回血唔超過 `maxHp` |
| 分影連擊 | 機率 `v` 再出一擊，第二擊威力 ×0.6（`COMBO_FOLLOWUP_POWER`） |

**演武台精英數值**：
- 血量 = 小兵 ×2.4（`SPAR_ELITE_HP_MUL`）
- 攻擊 = 小兵 ×1.35（`SPAR_ELITE_ATK_MUL`）

## 5. Edge Cases

- 金剛反震唔會震死主角（最少留 1 點血），勝負一定由敵人出手決定。
- 鐵布衫最少留 1 點傷害，唔會令攻擊變 0。
- 狂怒字喺每隻敵人身上只彈一次，火舌就一直保留。
- 連擊第二擊前，如果主角已經倒地，就唔再打。
- 舊存檔嘅交手冇 `foeTier` 同 `foeTrait`，當小兵處理，即冇特性。
- 演武台重新載入（`ensureLiveFoe` 或 `retreat`）時，特性狀態會跟住當前敵人重設。
- 所有隨機都用呼叫者傳入嘅 RNG（演武台用自己嘅 rand，交手用 `getRng`），結果 deterministic。

## 6. Dependencies

- `core/life/sparDuel.ts`：演武台關卡同對打
- `core/life/combat.ts`：事件交手
- `core/life/autoCombat.ts`：自動戰鬥；replay 帶 `traitFx`
- `src/spar/engine.ts`：演武台同 2D 後備畫面（描邊、光環、特性印、點綴色）
- `src/fx/highlight/duel/`：3D 自動戰鬥演出（shader 描邊同衣帶色、特性光霧、蓄力、特性印）
- `src/components/ink/InkBossIntro.tsx`：首領登場卡（名號、特性）

## 7. Tuning Knobs

全部係測試參數，記錄喺 `production/redesign-scope.md` 第 20 項。

| 特性 | 首領 | 精英 |
|------|------|------|
| 鐵布衫（減傷） | 30% | 15% |
| 開山蓄力（倍率／每幾擊） | ×2.2／3 | ×1.6／4 |
| 噬血（回血比例） | 35% | 18% |
| 分影連擊（機率） | 35% | 18% |
| 金剛反震（反震比例） | 20% | 10% |
| 狂怒（攻擊加成） | +60% | +30% |

其他可調數值：
- 演武台精英倍率：`SPAR_ELITE_HP_MUL` 2.4、`SPAR_ELITE_ATK_MUL` 1.35
- 精英數：`sparEliteCount`
- 3D 蓄力時間：`DUEL_TUNING.chargeSec` 0.45 秒
