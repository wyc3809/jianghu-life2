# EA0.115.0 全功能入口／相近功能盤點

玩家要求移除祖祠，主頁原位改為同遊江湖，並整合重複功能。只移除已指定祖祠操作，保留原存檔、已投資天賦、家傳武學與家族資料；不重置舊玩家。

| 範圍 | 檢視及處理 |
| --- | --- |
| 祖祠、創角祖蔭、總結祖蔭 | 全部撤可操作入口／彈窗掛載及無用途點數宣傳；既有核心資料不刪 |
| 首頁／江湖風雲的同遊 | 同一InkOnlinePanel／InkLiveWorld，首頁直接進同遊，返回鎮居；地圖入口直達同一同遊總頁並返回江湖地圖 |
| 幫會、門派會武、隨機對戰 | 同遊活動列集中入口，回到同一同遊頁；沿用原元件，沒有另造首頁專用副本 |
| 主頁武學、人物武學、線上對戰配搭 | 保持人物頁單一編輯入口及普通／對戰兩預設，捷徑只導航；不複製配搭邏輯 |
| 主頁秘笈閣、江湖秘笈閣、家族收藏／書頁 | 同一InkGachaPanel，收藏與兌換已在其中，不增加第二收藏／錢包 |
| 奇遇入口及進度條 | 同一encounter狀態，未完成定位進度、完成領取，保留有意義的狀態捷徑 |
| 修煉門派、門派會武 | 前者拜師／修習，後者真人每週選拔，不能刪其中一個或把本屆職位覆寫單機地位 |
| 開宗立派、真人幫會 | 前者NPC養成，後者真人組織／城池，保留各自資料及玩法 |
| 華山論劍、隨機對戰、開紅、門派／城戰 | 賽制、對手資格與獎勵不同，整合導航，不合併結算或更改經濟 |
| 人物詳情、戰力、身世／身法 | 各自資料用途不同；五維已按早前要求隱藏，不重新添加 |
| 族譜、人際、傳承 | 家人／家譜與繼承用途保留，不因祖祠移除刪家人、傳承或已獲武學 |
| 鎮居休息／醫治／商店、修煉／突破 | 操作消耗及結果不同，保留；共用原按壓／墨跡與彈窗，不另造同名按鈕 |
| 設定、排行榜、生命總結 | 跨頁共用現有元件；只移走祖祠提示，不刪必要保存／同步／錯誤資訊 |

本輪改動沒有存檔遷移、後端部署、概率／戰鬥／獎勵或私人錢包重設。離線畫面驗導航與資料保留，既有150檔回歸驗核心；不將離線導航當作新雲端容量／聊天驗收。
