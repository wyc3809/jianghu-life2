# 天賦、家傳與跨世繼承暫停 · EA0.116.0

玩家要求「天賦家傳等等機制同埋功能暫時唔需要，確保所有都已經收走」。此項取代第79項只移走祖祠入口、仍保留運作的處理。

| 路徑 | 本輪處理 |
|---|---|
| 祖祠／天賦／家傳面板 | 沿用已撤掛載；帳戶購買、選取、開第二格、開面板指令亦停用 |
| 創角／另起新生 | 核心忽略外部傳入的ancestry及legacy；不套天賦、家傳武學、姓名、前世根基、銀庫或裝備 |
| 一生結算 | 不記新祖蔭、世數、家傳解鎖譜或家族里程碑，不派相關玉石；普通收益照常入帳 |
| 生育／立嗣 | 子女照常出生；不自動立繼承人或新增家傳旗標，撤立嗣操作並封住直接指令 |
| 舊旗標 | 不再加每月族產銀兩、不排跨世劇本、不以舊宿敵替換華山對手名稱 |
| 傳承事件 | 暫停inheritance、event_064及legacy_script_*；舊pending清除、抽取與直接選項均阻擋 |
| 人物頁 | 撤歸隱傳位、繼承預覽、族譜入口及分頁，境界頁改名「境界修行」；保留人際 |
| 一生總結 | 重新產生展示文字，不再承諾銀庫、裝備、旁支承祧；舊summaryText留在原檔 |
| 接班彈窗 | 不掛載；再開人生不帶legacy、不顯示succession |
| 文案 | 家族收藏改秘笈收藏；普通奇遇改稱收穫，不以傳承命名 |

資料保護：保留舊祖蔭點、天賦投資、家傳選取、世數、旗標、年譜及帳戶資產。現有人物數值已混合歷史成長，不能可靠逆推，故不任意倒扣；停用期間沒有新的祖蔭套用、跨世轉移或相關定期收益。此項沒有新存檔schema，舊檔仍可來回讀寫。

正常系統：抽卡／升階／七卷／秘笈學習仍讀帳戶收藏；正常成就、日常、突破、演武與待入帳玉石保留；婚姻子女、門派制服、幫會、同遊及黑影戰鬥保持。普通家庭故事與NPC傳授並非家傳系統，仍保留；不把所有「傳」字故事一律刪除。

控制點是data/redesign/legacyFeatures.ts的固定產品開關，沒有玩家設定、網址或測試繞過。保留純歷史計算器供舊資料解讀及將來恢復；正式呼叫點均在停用守門後。相關舊測試改驗新產品行為，計算器測試繼續跑，沒有skip／刪測試。
