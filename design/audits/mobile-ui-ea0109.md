# 第68項：手機UI／UX、冊頁動效及文案清理

2026-11-14，基準EA0.108.0／fa204de，玩家要求全面檢視、按鈕入頁加動畫、貼近現有武俠手機遊戲，刪除帶開發說明感的文字標注。沿用現有宣紙、器物牌章、漫畫靜態人物及黑影戰鬥，不重設介面或玩法。

先用專案Playwright在390×844實際走22步，隔離存檔及封鎖雲端。Product Design audit框架用作檢查準則；本輪未提供該插件互動瀏覽器，截圖由專案既有Chromium流程取得，不冒稱使用插件瀏覽器或完整無障礙認證。未有已保存Product Design使用者設定。原始圖及DOM資料在.local-online/mobile-ui-polish/before，正式證據另整理到production/qa/evidence/redesign/mobile-ui-polish。

|步驟|畫面及觀察|處理|
|---|---|---|
|01、11–17|鎮居／修煉／江湖次頁；設定與玉石入口只有30px高|提升至44px，保留緊湊手機排版|
|02–10|人物、裝備、衣櫥、武學、詳情；主風格一致，裝備詳情按鈕僅18px高|詳情整行可按；統一短冊頁入場，選中回饋|
|03–06、08、10、19、21–22|原生modal焦點圍欄可用，但入場節奏不一致|共用anime.js短位移及淡入，不延遲確認或結算|
|07、09|武學介紹及規則文字密集，整段混合連招、回內、養成|常駐介紹簡化，規則按三個主題分段|
|04–06|衣櫥反覆顯示「只改外觀、不影響裝備與能力」及固定資格長句|只顯示當前制服資格或免費時裝狀態；保留不可換上原因|
|11–17|修煉／江湖多頁重複「按下方圓鈕過一月」|移除重複頁尾，保留真正耗盡提示與按鈕名稱|
|18–20|抽取與收藏已有獨立規則冊頁，扣費與概率是必要決策資料|保留真概率、付費測試標示及獎勵內容，不以刪字隱藏條件|
|所有按鈕|既有全域按壓會強制黑底及停止原動畫，部分新按鈕未完整涵蓋|沿用現有按壓監聽，改輕微按壓及原配色，補鍵盤／捲動取消|

已檢視本輪三份接觸板及22張原始畫面；沒有橫向溢出。完整範圍含鎮居、人物、裝備、造型、制服、時裝、武學／選擇／規則、更多、修煉、門派、雅藝、地圖、論劍、開宗、江湖風雲離線入口、秘笈閣、抽取規則、收藏、設定及祖祠。未登入真雲端、未操作已暫停多人戰、未測真iPhone或VoiceOver。

動效原則：按壓約120ms，冊頁／次頁約220–260ms，只動透明度及transform；動畫不阻擋輸入、不卡確認、不改傷害或RNG，取消／換頁／背景／減少動態即清理，不在修為ticker重播。重複按壓仍只由原生按鈕執行指令。
