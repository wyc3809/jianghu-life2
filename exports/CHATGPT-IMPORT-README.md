# 江湖一生 · ChatGPT 匯入說明

## 檔案
- `jianghu-life2-chatgpt-import.zip` — 完整專案原始碼（不含 node_modules / .git / dist）

## 怎麼用
1. 喺 ChatGPT 對話或 Project 上傳呢個 ZIP
2. 解壓後重點目錄：
   - `src/spar/` — 切磋演武引擎（動畫 A+B+C、剪影、單挑）
   - `public/ink/spar/sil/` — 水墨剪影 WebP
   - `src/components/ink/` — 水墨 UI
   - `core/life/` — 人生事件引擎
   - `data/` — 事件／裝備內容
3. 目前分支狀態約 **EA0.33.0**：HQ 剪影、身形縮小、一打一個敵人

## 本地跑（如需要）
```bash
npm install
npm run dev
```
