# 即時江湖 · 整合方案草稿

2026-11-15。玩家要求參考《靈劍江湖》，增加多人在線互動、對話、即時對戰及開紅，沿用現有數值並與遊戲配合。玩家已確認所有加入此功能的玩家均可開紅交手，戰敗後有保護；以下保留原討論及實作對照，不聲稱多人容量／延遲已驗收。

## 參考及已確認邊界

公開資料可確認《靈劍江湖》屬聊天室江湖脈絡；HKGAME首頁有2025-05-25靈劍二站公告。公開歷史介紹包括玩家對話、酒家、江湖事件及玩家交戰，但沒有登入測試其現行遊戲；不把2005年論壇介紹當作2026年現行規則，不照抄其數值、素材或介面。

本作第32項已確認：同一角色成長、自動逐招、對戰配搭、較低排名勝較高排名先直接換位、挑戰失敗不換位；PvP不新增傷勢、死亡、掉裝或後人接班。原非同步挑戰仍容許離線防守。這次新增同場模式，不把原離線防守暗中移除；新開紅是否只打同場在線角色屬新規則。舊幫會／門派戰及PR156仍暫停，本輪不順帶重啟。

先前已選自動逐招可直接沿用，不需要重複選；若玩家明確改為手動出招／走位，則需另訂操作、權威更新及持續執行服務範圍。目前待選的是新開紅的可攻擊範圍。

## 即時與權威執行

沿用Supabase Auth／Postgres，加Realtime做消息及在場提示。已查官方Presence／Broadcast／Authorization文件，後續實作前再查changelog與專案設定。

- Presence用作顯示在線；是否可攻擊、所在區域與有效身份，仍讀伺服器租約及成員記錄，不能相信前端廣播。
- 發言、私訊、入場、開紅、接受切磋及挑戰皆帶requestId，後端驗JWT、成員／區域／保護／忙碌狀態與限頻，再交易保存。沒有前端上傳傷害、勝負、名次或獎勵。
- 寫入消息／戰鬥事件後才通知相應私人頻道；RLS按成員及收發者授權，前端無權寫權威戰鬥事件。過期／退出／拉黑的權限撤銷和已連線訂閱重驗須實測，不把channel名稱當授權。
- 消息有持久ID／順序及補讀游標；Realtime遺失、重送或重連時補取快照與缺項，去重後顯示；不假設WebSocket永不漏訊。
- 首輪自動戰若沒有中途指令，可沿用伺服器固定戰報＋共同開始時間，兩端同步播放。這是真同場發起／接受與共享結果，但不是中途手動操控；不能將兩邊各算一份勝負冒充同步。
- 若加入逃跑、支援、用藥或中途選招，須升級成伺服器分步戰鬥與持久化指令／序號，或專用常駐權威服務；不能靠短生命Edge Function設timer當世界迴圈，亦不能只播已算完整結果仍聲稱指令可改戰局。
- 戰果、排名及任何新後果同一交易提交；背景、重播、跳過、斷線與重試不會再派獎。舊整份存檔上傳不得覆蓋新線上狀態。

暫定模型：online_zones、online_memberships、chat_messages／chat_threads、chat_blocks／chat_reports、live_battles、battle_events、pk_state及command_receipts。這是模型草圖，未建表；開紅狀態、區域與鎖要集中交易，避免兩次同時挑戰、換裝穿越、重連換身份或以舊租約逃離。

## 必須正面處理的現況

1. 現有heartbeat是2秒HTTP輪詢，戰報由讀取時補結算；未有真正即時聊天，也不等於常駐即時戰鬥服。世界目前單行revision／CAS及100人封測參數不可當承載保證；新消息與戰鬥需分區／分行，實測再報容量。
2. 戰鬥現時會從雲端saves讀角色，而saves由本人前端上傳。這可避免挑戰請求直接夾帶傷害，但**不代表人物成長已防篡改**。開放有排名／獎勵後果的開紅前，需定舊檔接納策略、可驗證裝備／武學來源及後續成長收據；不能只做Schema檢查便宣稱權威角色。保留原存檔，不擅自削弱或重置；未能驗證的歷史資料要明確標記及限制有價結果，規則待玩家確認。
3. 私訊與聊天同時交付拉黑、靜音、舉報、限頻及管理處理入口。文本以純文字呈現；身份／門派從伺服器讀，不從發言payload借名。私訊不會廣播到全服再靠前端隱藏。
4. 人生年月各人不同；社交、保護及戰鬥用伺服器現實時間，不因其他人過月、死亡／轉生或換裝改動已開戰快照。角色換世後以新lifeKey更新在場資料，舊場戰果仍只結算一次。

## 開紅選項（待玩家選）

A：明確標示的爭鬥區可襲擊同場在線玩家；城鎮／新手／保護中及新同場模式的離線角色不可被襲擊。這是建議首輪範圍，與原非同步離線應戰分開。

B：一般野外都可開紅襲擊同場在線玩家；安全城鎮／新手及保護中角色仍不可打，進場提示與紅名追蹤範圍更大。

兩者均不把「開紅」解成所有人強制雙方同意：切磋需接受，襲擊則按伺服器區域與資格判定。紅名能否被白名反擊、退出紅名的戰鬥鎖、惡名與名次後果另列規則；先前PvP不傷亡／不掉裝保持，除非玩家另改。

## 交付順序與驗收

1. 第一期：一個安全鎮景、同場名冊、同場對話／私訊、點人互動、拉黑／舉報及重連。先雙真身份驗聊天與權限，不先做假玩家聊天室。
2. 第二期：邀請切磋、共同時間軸與觀戰、對戰配搭／真公式、固定快照、戰報與重連追播；第三人只看公開戰況。
3. 第三期：確定開紅範圍／歷史角色信任策略後做襲擊、紅名、區域／新手／戰敗保護及原子結果；不順帶重啟幫會戰。

每期交付320／390／430真畫面及兩個獨立身份實際互動；測試越權、私訊洩漏、封鎖、重送、斷線、雙分頁、同時挑戰、重放不派獎、配搭保存與凍結、原存檔及舊排名模式不回退。手機鍵盤、安全區、減少動態與背景恢復要實測；網頁與TestFlight分開記錄，不用普通build成功冒充多人連線成功。

畫面沿用design/art/STYLE.md青綠暖金漫畫風、既有器物／頭像與黑影動作；只做本功能需要的場景，不重做首頁、現有人物或舊地圖。

## 2026-11-15 玩家定案及首輪實作

玩家已取代上面A／B區域選項：所有加入同遊功能的玩家均可被挑戰，不分地點／新手／境界；沿用30秒敗方保護，重入不清除，主動出擊解除自己保護。參與中離線自動應戰，只有明確「退出同遊」才停止參與，交手中不可退出取消戰果。收刀及屏蔽聊天都不免戰。

首輪公頻、私訊、名冊、開紅／收刀、指定交手、共同時間軸、觀戰、屏蔽及舉報一併接入原江湖風雲。這輪不另加邀請切磋或新惡名／懲罰／經濟；原隨機挑戰保留，新開紅不額外派玉石。消息獨立表，Realtime僅向本人通知版本，正文由驗證身份的Edge補讀；斷線補讀最近100條，並非無限完整歷史承諾。

世界仍沿用既有100人封測資料結構及CAS，以保持與舊排名／保護／戰鬥鎖一致；不是已完成分區大型MMO或負載驗收。消息不塞入世界JSON。現有存檔仍由用戶上傳，伺服器從該身份保存的數值組成戰鬥快照並拒絕挑戰夾帶數值，但未完成所有歷史成長來源驗證，不宣稱完全防改檔。
