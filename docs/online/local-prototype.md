# 第32項：本機雙帳戶多人江湖

玩家已確認嘅首版規則見 `design/proposals/jianghu-online-v1.md`。本批係真HTTP伺服器＋SQLite資料庫＋兩個瀏覽器帳戶嘅可操作原型，唔係用兩份前端localStorage扮聯機。正式版保持EA0.80.0，未租主機、未接正式登入／正式多人經濟，亦未上線。

## 啟動

需要Node 24及已安裝嘅專案依賴：

```bash
npm ci
npm run dev:online
```

- 遊戲：`http://127.0.0.1:5176/`，進入人生後揀「江湖」，最上方有「江湖風雲」。
- 直接試玩：`http://127.0.0.1:5176/?online=1`。兩個不同瀏覽器視窗／獨立context，分別選沈雲舟及謝清霜。
- 後端：`127.0.0.1:8787`；HTTP API經Vite同源proxy轉送。原型以兩秒心跳／輪詢同步，突斷線最多約八秒判離線。
- `ONLINE_WEB_PORT`、`ONLINE_PORT`可調前後端port；`ONLINE_DB`指定獨立SQLite路徑，預設`.local-online/world.sqlite`，已加入gitignore。
- 兩個程序都只綁loopback。原型登入只係選擇兩個測試身份，唔係正式帳戶驗證；唔好將呢個本機登入端點公開上網。

## 驗收步驟

1. A選沈雲舟（初始100名），B選謝清霜（初始20名），觀察對方在線狀態。
2. 可用「配搭武學」選已學外功，內功／身法各有獨立欄位，保存後由後端驗證。
3. B撳「離線留場」或關閉視窗，A仍可挑戰B。沈雲舟係方便驗收嘅較強測試角色，唔係正式平衡。
4. 觀看既有武學逐卷演出、兩倍速／跳過；勝方原本較低排名就互換，B返嚟會見到同一場戰報及名次。
5. 重播／重開頁唔再結算。敗方受短暫保護；敗方主動挑戰會解除自己保護。
6. 測試角色戰鬥氣血只用於本場快照，唔造成實際人物傷勢、死亡或家族接班；亦唔派切磋銀兩／掉裝。畫面唔顯示虛構戰利品。
7. 離線超過一分鐘返嚟可見少量待領收益；在線待領累積較多。收取只加到隔離試場銀兩。
8. 關閉並重開服務：戰報、排名、武學配搭、待領／已領銀兩、指令去重收據仍保留；到期戰鬥由服務自行完成。

## 明示測試參數

統一放 `data/redesign/onlineTestParams.ts`，畫面「試玩規則與測試值」亦可查看：

- 戰敗保護30秒；在線每分鐘10試場銀兩、離線每分鐘1，現行48小時離線累積上限保留。
- 心跳2秒、租約8秒；短暫背景／突斷線會有租約容忍。頁面隱藏／正常離場會通知服務，冇通知先等租約到期。
- 開戰後1.5秒由服務完成結算，逐招動畫係同一份結果嘅回放；回放長短唔控制結算時間。雙方會被鎖到結算，不能同時參加第二場。
- 最多40回合；拉鋸到上限暫以平手、不換位處理，只係原型後備，未定為正式平手規則。
- 每場雙方滿戰鬥氣血／內力快照，套用現有武學／卷數及基礎戰鬥純函數，唔呼叫原有人生勝負／傷亡流程；完整PvP流派與特殊效果平衡仍需後續驗證。
- 角色／人生seed42；後端預設獨立產生戰鬥種子，QA可設`ONLINE_TEST_SEED=42`重現。客戶端唔可以指定戰鬥種子、傷害、排名或獎勵。

以上獎勵種類、比例、保護時長、平手後備與配對細則都係測試值，唔當玩家已確認嘅正式經濟／戰鬥數值。

## 一致性與隔離

- 新路徑係`server/online/`、`core/online/`及`interfaces/online.ts`，唔修改演武台玩法／傷害或正式人生存檔。
- 所有指令用伺服器身份，Zod strict拒絕多加戰力／銀兩欄位。只能裝備後端已知已學武學，保留五外功＋獨立內功／身法。
- SQLite `BEGIN IMMEDIATE`原子處理雙方鎖定、換位、保護及收據；未完成戰鬥資料持久化。結算只做一次。
- 登入token由伺服器產生，資料庫只存hash；每個指令有requestId。同一帳戶／requestId重送返回原收據，換內容會拒絕。
- 客戶端遺失回覆時保留requestId；新快照回傳已確認收據供恢復。回放只讀，唔再提交開戰。
- 角色在線狀態合併同帳戶所有session；一個視窗離場唔誤判其他視窗離線。觀察離線對手唔會重設佢嘅48小時收益上限。
- `VITE_ONLINE_PROTOTYPE=1`只喺開發版開入口；正式Pages構建唔打包新UI或API客戶端。未將原型當正式反作弊或公開伺服器。

## QA

```bash
npx vitest run tests/online_rules.test.ts tests/online_service.test.ts
```

瀏覽器腳本係`scripts/qa/checkOnlinePrototype.py`。需要全新QA資料庫、seed42後端、API proxy前端5178，以及EA0.80.0基線前端5177。腳本使用390×844 DPR2、人生seed42及免費600／付費0；服務測試銀兩與玉石無關，使用隔離角色。

證據及最終報告見`production/qa/evidence/redesign/online-prototype/README.md`。瀏覽器自動化唔當iPhone真機、60fps或正式併發容量驗收。
