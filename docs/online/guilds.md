# 幫會及組織對話 · EA0.114.0

入口：江湖→江湖風雲→江湖幫會；已有門派會武入口保持。原開宗立派仍為NPC弟子養成。每個雲端身份可同時有一個真人幫會及一個既有門派，不互相覆寫。

## 幫會

可自創幫會、寫宗旨、向另一幫遞入幫帖或撤回；幫主／長老接納或婉拒。每人只有一個待批申請，入幫後清除；名冊唯一由服務端CAS及收據保證，不信前端職位。

幫主可任免長老、傳位及請其他人離幫；長老可處理申請及請普通幫眾離幫，不能處置幫主／其他長老。幫主須先傳位才可退出；只餘自己才可解散，解散後城池交還江湖、幫庫清除。一般成員可退出。管理確認為真原生彈窗，取消不發指令。

## 十城與幫庫

沿既有提案：洛陽、長安、襄陽、大理、成都、姑蘇、臨安、開封、泉州、揚州。無主城可進駐，有主城以當前本世對戰配搭對鎖定守將交鋒；沿現有simulateOnlineBattle真公式，守將離線仍可守城。守將保存進駐時配搭，幫主／長老可親自重新駐守。退出／換裝不改已鎖定守將；新城戰不改私人排名、傷亡、裝備或錢包。

城戰一次保存戰果／易手／次數／戰報／收據，演出只讀。捕獲後整備五分鐘；每人每日五次、間隔一分鐘，香港04:00換日。次數另按帳戶記錄，退幫／轉幫／重建不能洗次數。無主城進駐同樣計一次；非法／保護期間請求不扣次數。平手或敗方不易手。

每城每完整小時十份幫會資材，最多補計48小時。易手前先結清舊持有者，補讀只投影，真正操作才保存；不因多開頁或重試重派。資材只入幫庫，總堂由幫主建設，每級花100×目前級數；初始容納20人，每升一級加五人，最高五級。沒有新增私人銀兩／玉石／修為派獎，也沒有把佔城反覆易手當獎勵來源。

以上細額集中data/redesign/guildTestParams.ts，屬首輪封測候選，未寫成永久GDD；資源先按本輪建議的獨立幫會資材方案。最多50幫／200在幫身份，是資料規模限制，不是併發容量保證。

## 對話與隔離

幫會頻道只限目前幫眾；門派頻道同時核對報名名冊及當前雲端本世sectId。外幫／外派、退出後、偽造group或職位都不會取到正文。最近100條、300字上限、每發言者兩秒限頻；共用屏蔽名單，可解除或舉報。舉報存私有表，不自動對外發訊。

Realtime只送本人revision，正文仍經驗身份入口補讀。每次訂閱用獨立頻道ID，幫會名冊與對話可以同時更新，不互相移除訂閱。背景停補讀，返回或恢復網絡再追；已發指令遇斷線／5xx／429保留同內容ID，身份token續期不改重試索引。

新jianghu-organizations v1保持verify_jwt=true，入口再查Auth身份。新增guild_world、guild_reports、guild_receipts、organization_messages、organization_reports五表，皆RLS開啟、拒絕瀏覽器直讀及RPC執行，只service_role經SECURITY INVOKER交易。舊world／live／pair不重新部署；sect v3保持，migration 20261115100505只在缺少sect世界列時補空列，不覆寫現有名冊。

世界只帶私有管理狀態及鎖定守將；對外overview明列公開字段，不回守將完整人物或其他幫的申請。消息分表，舊公頻／私訊查詢不會讀到新組織消息。原成長仍可由本機保存上雲，不宣稱完整反作弊、現金交易資產或大規模負載已驗收。

## 驗證

prepareOrganizationQa.mts建立20個隔離fixture；checkOrganizationsCloud.py建立20個獨立匿名身份，保存真profile後做組織及兩派十席驗收。初次prepare後需管理工具只對記錄的測試城池回溯heldSince／accruedAt及移除整備時間，才能立即驗十小時收入與易手；正常整備拒絕先實驗，不改真玩家城池。ORGANIZATION_QA_PHASE=verify再核對易手、舊幫收入、建設重試及二十份原存檔hash。
